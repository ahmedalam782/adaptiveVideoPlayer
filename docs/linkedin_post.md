## Ready to post now — branch preview

I'm preparing the next update to adaptive_video_player, my open-source Flutter video player, and I'd love feedback before merging it into the stable branch.

The package reached a milestone shown in my pub.dev screenshot: 1.09k downloads, 19 likes and 160/160 pub points. Thank you to everyone who tried it and shared feedback! These are snapshot numbers, not live counters.

Here's what's in the branch compared with v1.3.3:

• Browser fullscreen and updated desktop window handling.
• Picture-in-Picture controls and background playback integration where supported.
• Chapter scrubbing, capsule controls and hold-to-2× playback.
• Audio/subtitle panels, a speed picker and an episodes drawer.
• Optional caching and platform-dependent screen capture controls.
• A refreshed example app and unified VideoConfig API.

The package targets Android, iOS, Windows, macOS, Linux and Web. Platform behavior and setup differ, so real-device feedback matters.

This is a v2.0.1 branch preview; the attached image is a concept mockup. The 160/160 score belongs to the published package, and the candidate still needs its release checks.
