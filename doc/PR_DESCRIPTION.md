# Preview v2.0.1 fullscreen, PiP and player controls

Compared with `master` (v1.3.3), this branch adds browser fullscreen, platform-specific PiP integration, chapter/gesture controls, audio/subtitle and episode panels, optional caching/capture controls, and a reorganized configuration API. It also adds native Android/iOS integration and refreshes the example app.

The README now explains how to try the feature branch before release, with a labeled concept mockup, migration notes, platform limitations and a launch guide. Historical popularity numbers are distinguished from the candidate's quality checks.
